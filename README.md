# Foodify

## Overview

Foodify is a self-initiated UI/UX concept for a food delivery app designed to create a simple, intuitive ordering experience from food discovery to delivery tracking.

## Project Goals

- Make food discovery simple and intuitive
- Create a clear restaurant browsing experience
- Simplify meal customization and checkout
- Provide clear order and delivery tracking

## Design Process

Discover → Explore → Order → Track

## Design Approach

Foodify focuses on clear visual hierarchy, consistent UI patterns, simple navigation, and a familiar local context.

- Canva
- UI/UX Design
- User Flow
